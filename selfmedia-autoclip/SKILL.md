# 工作流1 · AI 自动剪辑口播视频

**一条命令，素材进 → 成片出。** 真人出镜口播素材的全自动剪辑流水线。

## 核心能力

| 功能 | 说明 |
|------|------|
| 自动去气口 | 检测静音区间(< -30dB 且 > 0.45s)，两端各留0.15s自然呼吸，短停顿不剪 |
| 自动配字幕 | whisper语音识别，按裁剪区间重定时，跨区间句子切开不丢半句 |
| 自动挑BGM | 从BGM库按情绪匹配，混音闪避不压人声 |
| 竖屏适配 | cover裁满 / blur模糊背景+完整画面（横屏不裁脸） |
| 双水印 | 品牌标识+AI标识 |

## 四种模式

| 模式 | 输入 | 做什么 | 什么时候用 |
|---|---|---|---|
| `talk` | 真人口播视频 | 静音气口剪掉 → 字幕 → BGM → 竖屏 | 有真人出镜素材（最常用） |
| `mix` | 素材 + script.json | 素材做画面，脚本做TTS旁白 | 有素材但想用自己的稿子 |
| `card` | script.json | 卡片 + TTS旁白 | 完全没有实拍素材时兜底 |
| `auto` | 自动判 | 有script→mix；有音轨→talk；否则card | 不确定时用 |

## 关键参数

| 参数 | 作用 |
|---|---|
| `--fit cover\|blur` | 竖屏适配方式 |
| `--no-autocut` | 不去气口（保留原始停顿） |
| `--bgm auto\|none\|<mp3>` | BGM选择 |
| `--no-burn` | 不烧字幕，只出.srt |
| `--platform douyin\|video号\|xhs` | 多平台规格适配 |

## 产出

- `_final.mp4` 成片（1080x1920 / 原声 / 字幕 / BGM / 双水印）
- `.srt` 字幕文件
- `_cover.png` 封面（真人帧+大字标题）
- `发布清单.md` 多平台规格

## 铁律

- **AI 永不发布**：成片交人确认后人工发布
- 横屏素材用 `--fit blur`，否则裁竖屏会切脸
- 素材自带字幕时标记 `skip_subs`，防双层字幕

## 依赖

- Python 3.10+
- ffmpeg
- whisper（语音识别）
